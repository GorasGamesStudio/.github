## Ce qu'on fait

- **Jeux sur mesure** avec Unity : PC, mobile, VR.
- **Services en ligne** : API, comptes joueurs, scores et progression avec ASP.NET Core.
- **Sites et outils web** en C# avec Blazor.
- **Projets maison** : nos propres jeux, avec une identité assumée, brute et organique.

## Conventions

Tout le code C# du studio suit les mêmes règles : régions ordonnées, typage explicite, documentation XML en anglais, namespaces `GGS.NomDuJeu.Famille`.
